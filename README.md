# Data Days Visual Asset Kit

Welcome to the official visual asset repository for **Data Days**.

This repo contains downloadable graphics you can use to share your Data Days excitement across social platforms, including LinkedIn and other channels! Keep the world posted with the #DataDays hashtag!

## Official Event Page

For full event details, registration, and updates, visit:

## [aka.ms/DataDays](https://aka.ms/DataDays)

## What Is In This Repo

The `Images/` folder contains ready-to-use graphics, organized by theme:

- `Cert Loading/`: Assets related to certification progress and prep.
- `Flair/`: Decorative visuals and celebratory social graphics for you to give out to others!
- `I got certified/`: Shareable images for certification achievements.
- `Profile Rings/`: Profile overlays / ring-style social assets.

## How To Use These Assets

1. Browse the folders under `Images/`.
1. When you've clicked into the image you want to use, in the top right corner of the screen, you'll see a three-dot menu called "More actions." Open that menu and select **Download**
1. Download the image(s) you want to use.
1. Add them to your LinkedIn posts, profile updates, and other social channels.
1. Include the #DataDays hashtag so we can find your posts!
1. Special note for profile rings: you'll notice there's also a PowerPoint file in that folder. If it's easier for you, feel free to use that template, which contains both profile rings.

## Recommended Tagging

This is the most important part: we want to see how you’re using this swag! If you share on social, be sure to tag it with **#DataDays** so we can celebrate with you.

Data Days is built by the community, for the community - and this is just one more way to show up, connect, and recognize each other along the way.
