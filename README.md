# Data Days Visual Asset Kit

Welcome to the official visual asset repository for **Data Days**.

This repo contains downloadable graphics you can use to share your Data Days excitement across social platforms, including LinkedIn and other channels.

## Official Event Page

For full event details, registration, and updates, visit:

## [aka.ms/DataDays](https://aka.ms/DataDays)

## What Is In This Repo

The `Images/` folder contains ready-to-use graphics, organized by theme:

- `Cert Loading/`: Assets related to certification progress and prep.
- `Flair/`: Decorative visuals and celebratory social graphics.
- `I got certified/`: Shareable images for certification achievements.
- `Profile Rings/`: Profile overlays and ring-style social assets.

## How To Use These Assets

1. Browse the folders under `Images/`.
2. Download the image(s) you want to use.
3. Add them to your LinkedIn posts, profile updates, and other social channels.
4. Include a link to the official event page: **[aka.ms/DataDays](https://aka.ms/DataDays)**.

## Recommended Tagging

When posting, consider tagging your content with event-related hashtags and a short note about your Data Days learning journey.

## Brand And Usage Note

These assets are provided for community sharing and event promotion. Please keep visuals in their original form and avoid modifying official logos.
